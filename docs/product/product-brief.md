# ConstiuINT - Product Brief

> **Platform**: Mobile-first civic feedback application

ConstiuINT is primarily a **phone/mobile app** — web access is secondary. The Next.js web app serves as the backend and admin interface, but end-users access primarily via mobile browser or PWA.

## Product Thesis

ConstiuINT is high-trust constituency feedback infrastructure:

- constituent intelligence
- structured civic feedback
- future representative polling of direct constituencies
- timelier feedback loops
- less political text-spam

Not merely a message-to-representative app.

## Platform Strategy

### Current (Plan 1)
- Next.js web app (admin + public intake)
- Mobile-responsive web UI

### Future (Post-MVP)
- PWA for mobile installability
- Optional: React Native / Expo native app
- Mobile push notifications for:
  - Message status updates
  - Future: Representative polling participation

## Target Users

- Constituents who want structured feedback channels
- Mobile-first access patterns (not desktop)
- Federal + state legislative representation scope

## Key Metrics (Future)

- Mobile install rate (PWA/native)
- Submission completion rate on mobile
- Time-to-submit on mobile
- Admin response time
