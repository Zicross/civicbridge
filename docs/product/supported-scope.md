# Supported Scope

ConstiuINT MVP supports **national federal** and **state legislative** representation lookup only.

- No local/county/city or school‑board coverage is included in the MVP.
- Representative data is provided via a provider‑agnostic adapter (currently a fixture; production will use Geocodio/OpenStates after ToS review).
- UI must clearly indicate when a level is **unsupported** and must not claim full coverage.
- All lookup results include `source`, `asOf`, and `confidence` metadata.
