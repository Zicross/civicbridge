# CivicBridge

Working codename for a constituent-to-representative communication platform.

## Product idea

A constituent enters and verifies an address, then sees elected representatives at each relevant level of government. The app acts as a managed conduit for communications at first, with a future path toward representatives joining the app and messaging directly. A later revenue path may include political donation processing/conduit functionality, with a platform fee/cut.

## Current status

Bootstrap repo for planning and workflow design. No production code yet.
